Command center is the one page that ignores project boundaries. It collects
every task assigned to you, from every project you have access to, in every
workspace you belong to, and puts them in a single list. If you deliver work
across more than one client, this is the page you start the day on.

## What it collects

One rule: **tasks assigned to you**. Nothing else.

- Across **all projects** you have access to, not one project at a time.
- Across **all workspaces** you are a member of — your own workspace and a
  client's sit side by side.
- Every task carries its project, so you always know which piece of work you are
  looking at.

Tasks take [multiple assignees](/docs/roadmaps-and-work/tasks), so a task you
share with a colleague appears in both of your lists. It is the same task, not a
copy: whoever moves it, both of you see the move.

## Grouping and filtering

The list is only useful if you can aim it, so you can narrow by:

| Cut | Use it to answer |
| --- | --- |
| **Status** | What is actually in flight, versus everything I will ever owe |
| **Project** | What this one client is waiting on from me |
| **Date** | What is due this week, and what has already slipped |

Grouping by project is the honest view when you are deciding where the day goes.
Filtering to *In progress* is the honest view of how many things you have
genuinely started at once.

## Changing status from here

You can move a task's status without opening its project, and that change is the
same change you would make anywhere else.

> Moving a task to *Done* in Command center moves it on the project board,
> updates the task itself, and updates the derived status of the feature above
> it. There is no separate personal copy of the task to reconcile.

That last point matters. This is a *view*, not a to-do list you maintain
alongside the real plan. Ticking something off here is ticking it off for the
whole team.

## How it differs from the project board

The two look similar and answer opposite questions.

| | Command center | [The board](/docs/roadmaps-and-work/board) |
| --- | --- | --- |
| **Scope** | Every project, every workspace | One roadmap, in one project |
| **Whose work** | Only yours | Everyone's |
| **Question** | What do I owe, across everything? | How is this project moving? |

Use the board to run a project. Use Command center to run your own week.

## What it will not show

**Work that is not assigned to you.** A task you created, or a feature you care
about, does not appear here unless your name is on the task. Command center is
deliberately not "everything I am interested in" — that list would be as long as
the roadmap.

**Tasks in projects you no longer have access to.** If your
[project access](/docs/projects/access-and-roles) is removed, that project's
tasks leave your list immediately, even ones still assigned to you. Access is
evaluated live on every read, so the list can never show you work you are no
longer allowed to see. If a project vanished from here overnight, ask its owner
whether your access changed — the tasks themselves are untouched.

**Anything that is not a task.** Epics and features have no assignees; their
state is derived from tasks. Register entries — deliverables, change requests,
risks, decisions — live in their own project pages.

## Its neighbours

Command center is one of three personal, cross-project pages, and they split
cleanly:

- **Command center** — *work* assigned to you.
- **[Inbox](/docs/chat-and-meetings/direct-messages-and-inbox)** — *messages*:
  direct messages and the channel mentions waiting for a reply, across every
  project.
- **[Notifications](/docs/account-and-apps/notifications)** — *events*: someone
  assigned you a task, a meeting reminder fired, a change request was decided.

A useful habit: Notifications tells you what happened, Inbox tells you who is
waiting on a reply, and Command center tells you what to actually do next.

## On mobile

Command center is in the mobile app, with the same account and the same tasks —
it is the surface the app is best at, because it is exactly the list you want
when you are away from a desk. Assignment notifications arrive as push
notifications. See [The mobile app](/docs/account-and-apps/mobile-app).
